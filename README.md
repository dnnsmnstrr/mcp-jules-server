# Jules MCP Server

MCP server for Google Jules API integration. This server allows MCP-compatible clients to interact with the Jules API to manage coding sessions, list sources, and monitor progress.

## Prerequisites

- Node.js installed
- A Jules API key (get one from [jules.google.com/settings](https://jules.google.com/settings))

## Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Build the project:
   ```bash
   npm run build
   ```

## Running the Server

Set your Jules API key as an environment variable and start the server:

```bash
export X_GOOG_API_KEY=your_api_key_here
npm start
```

The server will start on `http://0.0.0.0:9000` by default.

## Connecting to the Server

This server uses the **SSE (Server-Sent Events)** transport.

- **SSE Endpoint:** `http://localhost:9000/sse`
- **Message Endpoint:** `http://localhost:9000/messages`

### Example Configuration for MCP Clients

If your MCP client supports SSE, you can configure it to connect to the endpoints above.

### Authentication

You can provide the Jules API key in two ways:
1. **Server-side:** Set the `X_GOOG_API_KEY` environment variable when starting the server.
2. **Client-side:** Send the `X-Goog-Api-Key` HTTP header with every request to the `/messages` endpoint. The server will prioritize this key if provided.

## Available Tools

- `list_sources`: List available repositories connected to Jules.
- `create_session`: Create a new coding session.
- `get_session`: Retrieve details and status of a specific session.
- `list_sessions`: List all sessions.
- `delete_session`: Delete a session.
- `send_message`: Send feedback or instructions to an active session.
- `approve_plan`: Approve a plan generated by Jules.
- `list_activities`: Monitor events and progress within a session.
